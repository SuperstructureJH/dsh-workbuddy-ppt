# Changelog

English | [中文](CHANGELOG.zh.md)

This file records public distribution changes. GitHub releases, npm publication,
marketplace listing, and native Office acceptance remain separate release gates.

## 0.1.1 - 2026-08-27

- Added 44 unique Kimi-compatible visual reference packs with complete design
  guidance and 332 readable reference pages.
- Added PPTD conversion, inspection, deterministic checking, local screenshot,
  editable rendering, packaging, and export commands to `dsh-pptd`.
- Added strict conversion receipts for normalized and unsupported PPTX features.
- Added native chart coverage for area, scatter, bubble, radar, and mixed
  secondary-axis charts.
- Added third-party attribution for the MIT-licensed template reference source.
- Published the corresponding GitHub release. npm publication remains a
  separately verified distribution action.

## 0.1.0 - 2026-08-27

- Published the first npm package and GitHub release.
- Shipped the installable `dsh.bundle` patch, Web client, Host plugin,
  `workbuddy-ppt` Skill, deterministic PPTD checks, and editable PPTX renderer.
- Verified installation into a fresh DSH Web profile and generation of a
  checked native-object PPTX.
- Kept Tencent SlideP and `editor_sdk` outside the public package.
